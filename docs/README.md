## Documentation rule

Keep product and technical decisions close to the relevant guide:

- Architecture changes go in `ARCHITECTURE.md`.
- Hosting, variables, and release steps go in `DEPLOYMENT.md`.
- Contributor workflow changes go in `CONTRIBUTING.md`.
